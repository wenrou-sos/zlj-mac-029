# 航空机务维修管理系统（MRO System）

覆盖机务维修核心流程的全栈演示系统：飞机档案、维修工卡、任务派工、步骤签署、缺件挂起、放行确认。

## 技术栈

- **前端**：React 18 + Vite + React Router（端口 5173）
- **后端**：Express（端口 3001）
- **数据库**：SQLite（sql.js / WASM 版 SQLite，数据持久化到 `server/mro.db`）

## 快速开始

```bash
# 1. 安装依赖
npm run setup

# 2. 初始化本地模拟机队数据（7 架飞机 / 8 名人员 / 10 张工卡）
npm run seed

# 3. 启动后端（终端 1）
npm run server

# 4. 启动前端（终端 2）
npm run client
```

打开 http://localhost:5173 。前端通过 Vite 代理将 `/api` 转发到 3001 端口。

> 提示：后端运行期间可随时执行 `npm run seed` 重置数据，服务监听数据文件变更会自动热加载，无需重启。

## 核心业务流程

```
待派工 ──派工──> 进行中 ──全部步骤签署──> 待放行 ──放行确认──> 已放行
                 ↑  │
                 │  └──缺件挂起──> 缺件挂起 ──航材到货──┘
                 └────────────── 自动恢复 ──────────┘
```

**业务规则**

- 步骤必须按顺序签署，且仅被派工人可签署
- 缺件挂起后禁止签署步骤；挂起期间可继续追加缺件登记，全部航材到货后自动恢复施工
- 放行校验：全部步骤已签署 + 无待航材缺件 + 放行人员资质（仅「放行人员」角色）
- AOG 工卡创建时飞机自动转「停场维修」；飞机所有工卡关闭后自动恢复「在役」
- 全部操作写入工卡日志时间线，可追溯

## 页面功能

| 页面 | 功能 |
|---|---|
| 维修驾驶舱 | 机队/工卡统计、紧急工卡、待航材缺件、最新动态 |
| 飞机档案 | 机队列表、单机档案（飞行数据/定检计划/工卡历史）、新增飞机、状态变更 |
| 维修工卡 | 状态/优先级筛选、创建工卡（含步骤编辑）、详情页操作台 |
| 工卡详情 | 派工、步骤签署、缺件挂起、航材到货、放行确认、操作日志 |
| 维修人员 | 人员资质（执照号/机型签署）、在手任务数 |

**身份切换**：右上角下拉框切换当前操作人（生产控制 / 机械员 / 放行人员），用于演示派工、签署、放行的权限控制。放行演示请切换至「王建国」或「李文静」。

## API 一览

```
GET    /api/dashboard                     仪表盘统计
GET    /api/aircraft                      机队列表
GET    /api/aircraft/:id                  单机档案 + 工卡历史
POST   /api/aircraft                      新增飞机
PATCH  /api/aircraft/:id                  更新状态/飞行数据
GET    /api/technicians                   人员列表（含在手任务数）
GET    /api/workcards                     工卡列表（?status=&priority=&aircraft_id=）
POST   /api/workcards                     创建工卡（含步骤）
GET    /api/workcards/:id                 工卡详情（步骤/缺件/放行/日志）
POST   /api/workcards/:id/assign          派工
POST   /api/workcards/:id/steps/:sid/sign 步骤签署
POST   /api/workcards/:id/hold            缺件挂起
POST   /api/workcards/:id/parts/:pid/arrive 航材到货
POST   /api/workcards/:id/release         放行确认
```

## 模拟数据

- **机队**：B737-800 ×2、A320neo ×2、A321neo、B787-9、ARJ21-700（含在役/定检中/停场维修状态）
- **人员**：放行人员 2、技术员 2、机械员 3、检验员 1，均带执照号与机型签署
- **工卡**：10 张，覆盖全部 5 种状态与 5 种类型（航线维修/定检/时控件/故障排除/改装）
